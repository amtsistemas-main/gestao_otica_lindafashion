Você está em um celular ou em outro sistema. Abra esta página no computador com Windows onde o sistema será instalado.

Como instalar

  1. Baixe o instalador pelo botão acima. O arquivo se chama OticaLindaFashion-Setup.exe.
  2. Abra o arquivo baixado.
    Se aparecer a tela azul “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. Isso só acontece na primeira instalação.
  3. Siga as telas do instalador e clique em Instalar. Não é preciso senha de administrador do Windows.
  4. Entre no sistema com o usuário e a senha fornecidos pelo administrador da loja.
Atualizações automáticasO sistema se atualiza sozinho. Não é preciso baixar de novo.
